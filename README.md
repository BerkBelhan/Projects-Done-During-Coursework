# Major Term Project

## Scaminator — E-Commerce Fraud Detector

**External Repository:**
[![Project Page](https://img.shields.io/badge/Project%20Page-Visit-green?style=for-the-badge\&logo=github)](https://github.com/BerkBelhan/fraud-detector)

A large-scale **LLM-powered multi-agent fraud detection system** developed as a term project for **SENG 472**.

Scaminator analyzes e-commerce listings, seller profiles, and user reviews to determine whether a product or seller may be fraudulent or suspicious.

---

## Project Overview

The system combines:

* Multi-agent AI architecture
* LLM-powered reasoning
* Web scraping
* Explainable AI outputs
* Trust score generation

The project produces:

* Fraud likelihood analysis
* Trustworthiness scoring (0–100)
* Explainable reasoning
* Actionable user recommendations

---

## Core Features

### Multi-Agent Investigation System

Separate AI agents independently analyze:

* Product descriptions
* User reviews
* Seller information

### LLM-Powered Reasoning

Uses:

* Google Gemini API
* Custom reasoning pipelines
* Aggregated agent outputs

### Explainable AI

The system provides:

* Detailed verdicts
* Confidence reasoning
* Fraud indicators
* User safety recommendations

### Modular Architecture

Designed for:

* Easy extension
* Additional investigators
* New marketplaces or data sources
* Scalable analysis workflows
